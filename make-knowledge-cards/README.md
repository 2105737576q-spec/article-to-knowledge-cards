# make-knowledge-cards

把一篇文章或本地文本文件，整理成一组便于记忆和复习的**知识卡片**的 Agent Skill。

## 1. 项目解决什么问题

阅读长文、论文或笔记后，信息量大而散，难以抓住重点、不易复习。本项目通过把文章交给 Agent 自动提炼，输出**每张只讲一个知识点**的结构化卡片，帮你：
- 快速抓住原文真正重要的知识，而不是照搬全文；
- 用"核心知识 + 简明解释 + 例子/自测问题"的形式加深理解、便于记忆与复盘。

## 2. 主要功能

- **输入**：直接粘贴的文章，或本地的 **Markdown / TXT** 文件路径。
- **输出**：**5~8 张**知识卡片（信息不足时如实减少），每张卡片固定 4 部分：**标题 / 核心知识 / 简明解释 / 例子或自测问题**。
- **只保留重要知识**：通读全文 → 识别候选知识点 → 去重合并 → 筛选最重要的 5~8 个 → 逐张写卡。
- **不编造**：所有内容源自原文，不添加原文没有的信息。
- **不强行凑数**：有效知识点不足 5 个时，产出更少的卡片是正确行为。

> 暂不支持：网页抓取、PDF、Anki 和图形界面。

## 3. 安装方法

本项目是一个 **Agent Skill（目录）**，不是 Python 包或 CLI，无需 `pip install`。

**第 1 步**：把整个 `make-knowledge-cards/` 目录放到 Agent 的 Skill 加载目录（例如 `workspace/.user_skills/` 或你所在环境的技能根目录，按 Agent 的技能发现规则放置）。

**第 2 步（可选）**：校验 Skill 结构，需 Python 环境装有 `pyyaml`：

```bash
pip install pyyaml
python quick_validate.py make-knowledge-cards   # 输出 "Skill is valid!" 即通过
```

（`quick_validate.py` 来自官方 `skill-creator-for-work`，用于检查 SKILL.md 的 frontmatter 与命名规范。）

## 4. 使用方法

安装后，直接对 Agent 用自然语言提出需求即可，例如：

- “帮我把这篇文章做成知识卡片”（并粘贴文章）；
- “把 `D:\notes\某文.md` 整理成卡片”；
- “对这段内容生成复习卡片”。

Agent 会按 Skill 流程自动完成：通读 → 提炼知识点 → 去重 → 筛选 5~8 个 → 逐张输出卡片。

## 5. 输入输出示例

**输入**（一段短文）：

> 水在标准大气压下，100 摄氏度时会沸腾。沸腾时液体内部和表面都会剧烈汽化，产生大量气泡。水的沸点会随着气压的降低而降低，所以海拔高的地方水不到 100 度就会沸腾。

**输出**（信息不足时只出 2 张，不凑数）：

```
### 卡片 1｜水的沸腾条件与定义
**核心知识**
- 标准大气压下，水在 100℃ 沸腾。
- 沸腾时液体内部和表面都剧烈汽化，产生大量气泡。
**简明解释**
水被加热到足够温度后，从内部到表面一起冒泡翻腾的状态。
**自测问题**
在标准大气压下，水的沸点是多少摄氏度？

### 卡片 2｜沸点随气压降低而降低
**核心知识**
- 水的沸点会随气压降低而降低。
- 海拔高的地方气压低，水不到 100℃ 就会沸腾。
**简明解释**
气压越低水越容易够到沸点，高原烧水不用到 100 度就开了。
**例子**
在高山上烧水，不到 100℃ 就沸腾，饭容易煮不熟。
```
