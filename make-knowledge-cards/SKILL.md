# Make Knowledge Cards

把一段文章或本地文本文件整理成一组便于记忆和复习的知识卡片。目标是保留原文真正重要的知识，而不是照搬全文。

## 输入方式

- **直接粘贴文章**：用户把整篇文章/段落贴在消息里，直接处理。
- **本地 Markdown / TXT 文件**：用户提供文件路径，先用读取工具打开文件、完整读取内容后再处理。不要只看文件名或摘要就动手。
- 一次只处理一个来源。若同时给出文章和文件，以用户明确指出的为准；未指明则以先提到的、或更完整的一份为准。

## 工作流程

1. **通读全文**：完整读取输入，理解文章主题、结构和论证主线，先抓住整体，再定位具体知识点。
2. **识别候选知识点**：找出文章真正讲到的、对读者有信息增量的关键点（概念定义、原理机制、方法步骤、结论、数据规律等）。跳过背景铺垫、客套、重复举例和无信息量的过渡句。
3. **去重合并**：删除重复或高度相近的表述；同一知识点在不同位置反复出现时合并成一个卡片，不重复出卡。
4. **筛选并确定卡片数量**：从候选点中选出**最重要**的 5~8 个知识点。只有真正够格的知识点才能出卡。若原文信息不足、有效知识点不足 5 个，则**如实出 5 张以内（甚至更少）的卡片，绝不强行凑数**，也不为凑数量而拆分、臆造或放大原文没有的内容。
5. **逐张写卡**：按下方卡片结构，为每个知识点单独写一张卡片。

## 卡片结构（每张卡片固定 4 部分）

每张卡片按以下顺序输出，且**一张卡片只讲一个知识点**：

### 标题
- 用一句简短的话概括该知识点（建议不超过 20 字），让人一眼知道这张卡片讲什么。

### 核心知识
- 用 2~4 行讲清这个知识点最核心的内容：概念是什么、关键机制、关键结论或要点清单。
- 信息全部来自原文，不得添加原文没有的信息、推断或补充知识。

### 简明解释
- 用更通俗、更口语的话把这个知识点再讲一遍，帮助理解。可以换一种说法、给一个直觉类比，但不可偏离原文含义，也不可引入原文未提的类比内容。

### 例子 或 自测问题（二选一）
- 若原文提供了具体例子、数据或案例，优先提炼成**例子**呈现。
- 若原文没有可用的例子，就写一道基于本卡片知识的**自测问题**，用于检验是否记住。
- 只在“例子”和“自测问题”中选一个，不要两个都写。

## 输出格式

卡片与卡片之间用空行分隔。每张卡片用以下结构输出（用清晰的分节标题）：

```
### 卡片 1｜<标题>

**核心知识**
- ...

**简明解释**
...

**例子**（或 **自测问题**）
...
```

- 所有卡片输出在一条回复里，按知识逻辑或原文顺序排列。
- 卡片总数为 5~8 张，除非信息不足而降为更少。
- 末尾可加一行「共 N 张」的提示，帮助核对数量。

## 硬性规则

1. **不编造**：卡片内容必须源自原文。原文没有的细节、数据、结论一律不写；解释和类比不得引入原文未提及的信息。
2. **一张一知识点**：每张卡片只讲一个独立知识点，不要在一张卡片里塞多个点。
3. **删除重复**：重复或高度相似的内容只保留一张卡片。
4. **不强行凑数**：信息不足时产出少于 5 张卡片是正确行为；不要拆分知识点、不要放大细节来凑够 5 张。
5. **忠实原文**：涉及数据、比例、专有名词时与原文保持一致，不四舍五入改写含义。
6. **不越界**：不主动抓取网页、不解析 PDF、不生成 Anki 包、不提供图形界面；这些超出本技能范围。
